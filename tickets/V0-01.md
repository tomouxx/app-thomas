## Contrat

- Paquet `cabinet` en disposition `src/`, version `0.1.0` déclarée dans `pyproject.toml`.
- `cabinet.web.app.create_app() -> FastAPI`.
- Route `GET /sante` qui renvoie le code 200 et `{"statut": "ok", "version": "0.1.0"}`.
- Commande `cabinet` (typer) avec la sous-commande `cabinet version`.
- Cibles du `Makefile` : `install` (environnement virtuel `.venv` et `pip install -e ".[dev]"`), `check` (`ruff check .` puis `pytest -q`), `run` (uvicorn sur `127.0.0.1:8765`).

## Précisions de la spécification

- `pyproject.toml` déclare dès maintenant toutes les dépendances d'exécution de `specs/03 §6`, les règles de ruff de `specs/01 §5` et `requires-python = ">=3.12"`.
- `cli.py` déclare une fonction de rappel vide (`@app.callback()`). Sans elle, `cabinet version` échoue tant que `version` est la seule commande (`specs/03 §5`).
- `create_app()` désactive les pages de documentation de FastAPI (`specs/08 §1.1`).

## Critères d'acceptation

1. `make install` réussit dans un environnement vierge.
2. `make check` lance ruff puis pytest et sort avec le code 0.
3. `GET /sante` renvoie 200 et le JSON du contrat, avec la version lue depuis les métadonnées du paquet.
4. `cabinet version` affiche `0.1.0`.
5. La cible `run` lie le serveur à `127.0.0.1` et à aucune autre interface (le test lit le `Makefile`).
6. `.gitignore` exclut `.venv/`, `__pycache__/`, `*.db` et `.pytest_cache/`.
