## Objectif

Transformer un transcript Teams déposé (.vtt ou .docx) en texte rattaché à sa réunion.

## Fichiers à créer ou modifier

- `src/cabinet/ports/transcriber.py`
- `src/cabinet/readers/teams_vtt.py`
- `src/cabinet/readers/teams_docx.py`
- `src/cabinet/agents/transcripts.py`
- `src/cabinet/agents/pipeline.py`
- `tests/unit/test_teams_readers.py`
- `tests/fixtures/transcripts/`

## Contrat

```python
class Segment(BaseModel):
    start_s: float | None; end_s: float | None; speaker: str | None; text: str

class TranscriptData(BaseModel):
    text: str
    segments: list[Segment]

def read_vtt(path: Path) -> TranscriptData: ...
def read_docx(path: Path) -> TranscriptData: ...
```

- `TranscriptData`, `Segment` et le protocole `Transcriber` de la section 5.1 vivent dans `ports/transcriber.py`.
- `read_vtt` lit le format WebVTT, y compris les balises d'orateur `<v Nom>`. Le texte complet reprend les segments dans l'ordre, une ligne par segment, préfixée par l'orateur quand il est connu.
- `read_docx` lit les paragraphes avec `python-docx`. Format supposé : une ligne « orateur puis horodatage », suivie du texte. Si aucune ligne de ce type n'est reconnue, le lecteur renvoie tout le texte en un seul segment sans orateur.
- `TranscriptsAgent` (nom `transcripts`) traite les `inbox_item` à l'état `pret` de nature `teams_transcript`. Il crée un `transcript` de source `teams`, passe l'élément à `traite` et déplace le fichier vers `traite/AAAA-MM/`. Un fichier illisible passe à `erreur` avec le message, et l'agent continue.
- L'agent est ajouté au pipeline après `agenda`.

## Critères d'acceptation

1. Un fichier WebVTT avec orateurs donne les segments, les orateurs et les horodatages attendus.
2. Un fichier WebVTT sans balise d'orateur est lu, avec `speaker` à `None`.
3. Un `.docx` au format supposé donne un segment par prise de parole.
4. Un `.docx` de texte libre donne un seul segment contenant tout le texte.
5. Après l'agent, l'élément est `traite`, le fichier est dans `traite/AAAA-MM/` et le `transcript` est rattaché à la bonne réunion.
6. Un fichier corrompu passe à `erreur` et les autres fichiers sont traités.
