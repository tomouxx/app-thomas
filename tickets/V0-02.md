# V0-02 · Client du modèle local et garde de bouclage

Vague 0. Dépend de : V0-01. Sections de `SPEC.md` à lire : 3, 5.1, 9.

## Objectif

Parler au modèle local par HTTP, obtenir des réponses JSON validées, et refuser toute adresse qui n'est pas locale.

## Contrat

```python
class Message(BaseModel):
    role: Literal["system", "user", "assistant"]
    content: str

class LLMResult(BaseModel):
    text: str
    parsed: BaseModel | None = None
    prompt_tokens: int | None = None
    completion_tokens: int | None = None

class ConfigError(Exception): ...
class LLMError(Exception): ...

def assert_loopback(base_url: str) -> None: ...

class LocalLLM:
    def __init__(self, base_url: str, model: str, timeout_s: float = 300,
                 transport: httpx.BaseTransport | None = None): ...
    def complete(self, messages, schema=None, images=None) -> LLMResult: ...
```

- `assert_loopback` accepte les hôtes `127.0.0.1`, `localhost` et `::1`. Tout autre hôte lève `ConfigError`, sauf si la variable d'environnement `CABINET_ALLOW_REMOTE_LLM` vaut `1`. Le constructeur de `LocalLLM` l'appelle.
- `complete` envoie `POST {base_url}/chat/completions` avec `model`, `messages` et `temperature` à 0.2.
- Avec `schema`, un message système ajouté en tête demande une réponse en JSON seul et donne le schéma JSON du modèle pydantic. La réponse est débarrassée d'éventuelles clôtures de bloc de code, puis validée. En cas d'échec de validation, le client relance en ajoutant l'erreur au dialogue, deux fois au plus. Après trois réponses invalides il lève `LLMError`.
- Avec `images`, le contenu du dernier message utilisateur devient une liste : un élément texte, puis un élément `image_url` par image, en URI de données base64.
- Une erreur HTTP ou un délai dépassé lève `LLMError` avec un message en français.
- `cabinet llm-test` demande au modèle `{"ok": true}` et affiche `OK`. En cas d'échec le code de sortie est 1.

## Critères d'acceptation

1. `http://127.0.0.1:8080/v1` et `http://localhost:4000/v1` sont acceptées. `https://api.exemple.test/v1` lève `ConfigError`.
2. Avec `CABINET_ALLOW_REMOTE_LLM=1`, une adresse distante est acceptée.
3. Sans schéma, `complete` renvoie le texte de la réponse et les compteurs de tokens quand le serveur les fournit.
4. Avec schéma, une réponse JSON valide est renvoyée dans `parsed`, y compris quand elle est entourée d'une clôture de bloc de code.
5. Deux réponses invalides puis une valide donnent un succès en trois appels. Trois réponses invalides lèvent `LLMError`.
6. Avec une image, le corps de la requête contient un élément `image_url` dont l'URL commence par `data:image/`.
7. Un code HTTP 500 lève `LLMError`.
8. Aucun test n'ouvre de connexion réseau (transport `httpx.MockTransport`).
